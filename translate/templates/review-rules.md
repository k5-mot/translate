# Review Rules

- 翻訳の正確さを最優先し、構造保持、実行コスト、見た目の順に評価する。
- 意味の欠落、追加、否定、条件、比較、因果関係、数値、単位を検査する。
- 用語集の原語は大小文字と連続空白を正規化し、英数字の端の単語境界を確認する。Capital内のAPIのような部分一致だけでは指定訳の欠落を指摘せず、実際に原語がある場合の指定訳を検査する。
- 固有名詞・略語・一般の識別子は表記の完全一致を要求しない。U.S. → 米国のような自然な訳を認める。
- 明確なURLとファイル名の欠落・変更はwarningとして確認し、それだけを理由にerrorへ昇格させない。構造化Codeの内容とLinkの参照先は維持する。
- 修正は指摘箇所へ限定し、原文にない情報を追加しない。
- 原文がページ境界などで文の途中でも、原文末尾より後を推測して欠落と判定しない。訳文が日本語の語順上完結して見えること自体は問題にせず、原文にない意味や後続内容を追加した場合だけ指摘する。
