## ADDED Requirements

### Requirement: 計測表示の障害で本処理結果を変更しない
Systemは、TaskおよびCLI/Streamlit入口の経過時間表示で同期的な出力stream障害が発生しても、表示のみを省略し、本体の戻り値、元の例外および本体が定めた終了状態を維持しなければならない（MUST）。対象は接続の切れたpipe、閉じたstreamおよび出力時のI/O障害とし、計測表示の失敗によって本体を再実行してはならない（MUST NOT）。本処理、成果物保存、Checkpoint保存の失敗と利用者による中断をこの規則で抑制してはならない（MUST NOT）。正常時の計測表示形式と出力先を維持し、計測表示を独立した完了・再開状態として保存してはならない（MUST NOT）。Q-RELとして、対象障害を成功・失敗それぞれへ注入する自動Testで結果の置換を0件としなければならない（MUST）。本要件は計測出力呼出中に検出する障害を対象とし、一般の出力やprocess終了時に初めて検出される遅延flush障害の復旧は対象外とする。

#### Scenario: 成功した処理の計測表示が失敗する
- **WHEN** 本体が成功し、経過時間表示で対象のstream障害が発生する
- **THEN** Systemは本体の成功結果を維持し、計測表示を省略し、本体を再実行しない

#### Scenario: 失敗した処理の計測表示も失敗する
- **WHEN** 本体が例外で終了し、その後の経過時間表示で対象のstream障害が発生する
- **THEN** Systemは計測例外へ置換せず、本体の元例外と失敗状態を維持する

#### Scenario: 公開入口の合計時間表示が失敗する
- **WHEN** CLIまたはStreamlit入口の本体が正常終了または例外・終了通知で終了し、合計時間表示だけが対象のstream障害で失敗する
- **THEN** Systemは本体が定めた終了状態を維持する

#### Scenario: 保存処理自体が失敗する
- **WHEN** 本体の成果物保存またはCheckpoint保存が失敗する
- **THEN** Systemは保存失敗を伝播し、計測表示の省略を理由に成功扱いしない

#### Scenario: 計測表示中に利用者が中断する
- **WHEN** 計測表示中に利用者による中断が通知される
- **THEN** Systemは中断を通常の出力stream障害として抑制しない

#### Scenario: 計測表示が正常に終わる
- **WHEN** Taskまたは公開入口の経過時間表示が成功する
- **THEN** Systemは従来どおりの形式と出力先へ一度だけ表示し、完了状態の別管理を追加しない
