## ADDED Requirements

### Requirement: 表紙を本文図の採番へ含めない
Systemは、翻訳成果物の表紙画像を本文図の自動採番および図一覧の対象に含めてはならない（MUST NOT）。表紙の有無で本文図の自動番号を変化させず、最初の採番対象の本文図を1として文書順に採番し、本文と図一覧の番号を一致させなければならない（MUST）。表紙の代替説明・先頭配置・改ページを保持し、採番の調整を理由に本文Captionの文字列または表の番号を変更してはならない（MUST NOT）。Q-FUNC/Q-COMPとして、表紙あり/なしの同じ本文の変換を比較するTestで、表紙による本文図の番号差を0件にしなければならない（MUST）。

#### Scenario: 表紙に続いて本文図を出力する
- **WHEN** 表紙画像とCaptionを持つ本文図を出力する
- **THEN** 表紙は番号・Caption・図一覧項目を持たず、本文図と図一覧の最初の自動番号は1になる

#### Scenario: 表紙の有無を比較する
- **WHEN** 同じ本文図列を表紙あり/なしで変換する
- **THEN** 本文図と図一覧の自動番号・Caption内容は両方で同じになり、表紙ありの場合は先頭画像とその後の改ページが保持される

#### Scenario: 複数図と表を含む
- **WHEN** 表紙に続いて複数の採番対象図と表を変換する
- **THEN** 本文図は1から文書順に採番され、表の採番とCaption中の既存の文字列は変更されない

#### Scenario: 採番対象の本文図がない
- **WHEN** 表紙だけ、または表紙とCaptionなし画像・表を含む文書を変換する
- **THEN** 表紙のために図番号や図一覧項目を生成せず、Captionなし画像へ新しいCaptionを付けない
