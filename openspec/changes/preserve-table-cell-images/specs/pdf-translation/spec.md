## ADDED Requirements

### Requirement: 表内画像の所属と表示を保持する
Systemは、原文の表セルに属する画像を同じ論理セル内へ一度だけ出力し、画像参照、原本上の寸法、付随Captionを中間保存と日本語Markdown/DOCXで保持しなければならない（SHALL）。行列の結合領域とセル本文を保持し、画像を独立した表外の図へ重複出力してはならない（MUST NOT）。表紙は既存の第1ページ画像出力契約に従う。

Q-FUNC/Q-RELとして、既知行列のfixtureで画像の欠落・重複・誤セル配置を0件にする。Q-INTとして、寸法を保持するfixtureでは原本ptから換算したDOCX画像寸法との誤差を1 EMU以内とし、Word PDFで判読性を検証する。

#### Scenario: 表内の空セルに状態画像がある
- **WHEN** 文字のないセルに画像があり、原文上の位置から所属行列を一意に確定できる
- **THEN** Systemは画像を該当セル内に保持し、空訳と誤判定せず、表外へ再出力しない

#### Scenario: 結合セルと複数画像を保持する
- **WHEN** 行または列を結合したセルへ一つ以上の画像が所属する
- **THEN** Systemは結合領域の起点に画像を一度ずつ保持し、セル本文・Captionとともに中間保存後も欠落なく出力する

#### Scenario: 表外の通常の図を保持する
- **WHEN** 画像にセル所有の根拠がなく、表と重ならず独立している
- **THEN** Systemは近いという理由だけで表へ移さず、通常の図として保持する

### Requirement: 表内画像の不確かな所属を公開しない
Systemは、セル参照がある画像、または同一ページの表領域と重なる画像の所属を検査しなければならない（MUST）。所属セルが複数・不明、参照と位置が矛盾、または必要な幾何情報が不正な場合は、推測配置や表外退避で成功扱いにせずWorkflowを停止し、再開可能な状態を保持しなければならない（SHALL）。部分的な結果で既存成果物を上書きしてはならない（MUST NOT）。

Q-RELとして、曖昧な境界と障害注入のfixtureで後続成果物公開0件、入力・既存成果物の変更0件を確認する。Q-SECとして、失敗診断は対象IDと安全な理由に限定し、本文・画像bytes・秘密値を含めてはならない（MUST NOT）。

#### Scenario: セル参照と位置が食い違う
- **WHEN** 一つの画像が複数セルに所有される、または明示したセルと原本上の位置が矛盾する
- **THEN** Systemは任意の候補を選ばず、所属エラーとして停止し、再開用状態を保持する

#### Scenario: 幾何情報から所属を確定できない
- **WHEN** 表内または表境界に重なる画像について、座標原点・ページ寸法・セル位置が欠損または不正で、所属を一意に確定できない
- **THEN** Systemは画像を欠落させたり表外へ逃がしたりせず、成果物公開前に停止する

#### Scenario: セル画像の参照先や構造が壊れている
- **WHEN** 中間保存後のセル画像が欠落asset、許可領域外asset、不正寸法、または描画不能な所属構造を持つ
- **THEN** Systemは公開前に拒否し、入力と既存の完全な成果物を保持する
