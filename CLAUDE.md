# Repository Instructions

## Scope

- MUST respond to users in Japanese.
- MUST add a generic AI-assisted trailer to the commit message when AI was
  used for the commit.
- MUST NOT use an AI service as the author name or email address.
- MUST follow the [CONTRIBUTING_GUIDELINE](docs/CONTRIBUTING.md), when developing.
- MUST follow the [CODING_RULES](docs/CODING_RULES.md), when implementing code.
- MUST follow the [DOCUMENTATION_RULES](docs/DOCUMENTATION_RULES.md), when writing documentation.

## Working in this repository

- Keep changes small and reuse existing code and dependencies.
- Do not disclose credentials or contents of secret files.
- Report commands actually run and label untested behavior accurately.
- This repository is a Python project. Use its existing uv, Ruff, ty, and pytest
  configuration; do not introduce a new task runner.
- Keep source files UTF-8 with LF line endings and use OS-independent paths.
